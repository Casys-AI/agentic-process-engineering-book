# Agentic Process Engineering

Published editions of the handbook by Erwan Lee Pesle, maintained by Casys AI.

Read the handbook and its edition history on [Casys](https://casys.ai/agentic-process-engineering/book), or download the PDF and HTML reading bundle from [GitHub Releases](https://github.com/Casys-AI/agentic-process-engineering-book/releases).

Each edition has a matching version label in the book, release notes and downloadable files. Older editions remain available. This repository contains distribution information; the releases contain the published reading files.
